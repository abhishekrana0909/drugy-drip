# Drugy Drip: website

Website for **Drugy Drip**, a baggy streetwear brand (oversized tees, hoodies, cargos, baggy jeans, caps).

It's a plain HTML/CSS/JS site, no framework. Customers add products to a cart and the cart sends the order to WhatsApp.

## Pages

| File | What it shows |
|---|---|
| `index.html` | Home: hero slider, collections, best sellers, order-on-WhatsApp, new arrivals, banners, lookbook |
| `shop.html` | All products with category filter, search and price sort |
| `contact.html` | Message form (opens WhatsApp), how to order, size help |

## Open it on your computer

```bash
python -m http.server 5501
```

Then open http://localhost:5501 in the browser.

## Change products, prices or contact details

The pages are **generated by a Python script**, so edit these files instead of the `.html`:

- `tools/site-builder/config.py`: WhatsApp number, Instagram, email, city (currently DEMO values)
- `tools/site-builder/products.py`: all products and the price per category (USD)
- `tools/site-builder/page_home.py`, `page_shop.py`, `page_contact.py`: page text and sections
- `tools/site-builder/layout.py`: header, footer, product card

After editing, run:

```bash
python tools/site-builder/build.py
```

Styles are in `css/style.css`, behaviour in `js/main.js` and `js/cart.js`. After changing those, bump `ASSET_VERSION` in `config.py` and rebuild so browsers load the new file.

## Logo

- `images/logo/source/druggy-drip-original.jpg`: the logo in use (header, footer, favicon)
- `tools/logo/`: scripts that drew the earlier logo options (`make_logo.py`, `make_logo_real.py`, `make_logo_leafcut.py`) and `render_png.py` to export PNGs

## Product photos

All clothing photos are cut from the brand's mockup sheets in `images/source/` by:

```bash
python tools/crop_mockups.py
```

Change the crop boxes in that file if you add a new sheet.
